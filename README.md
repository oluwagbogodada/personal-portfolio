# Oluwagbogo Dada — Personal Portfolio

A responsive personal portfolio built with Next.js, presenting selected work across digital publishing, e-commerce and institutional digital experiences.

## Featured projects
- VeritaPost
- Asa Moremi
- NANS HQ
- GistOrbit

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production build
```bash
npm run build
npm run start
```

## Deploy
Connect this repository to Netlify. Netlify supports Next.js and can automatically build and deploy updates whenever changes are pushed to the connected Git repository.

## Before publishing
Review the project descriptions and links. Add approved screenshots, confirm the correct live URLs for VeritaPost and Asa Moremi, and adjust any wording that does not accurately reflect the delivered work.
